1 Propósito y Enfoque del Proyecto

La plataforma digital de ATLAS GYM ha sido concebida como un sistema exclusivo y a medida para el establecimiento. A diferencia de las soluciones genéricas del mercado que mezclan múltiples empresas en una misma base de datos, este desarrollo cuenta con recursos de computación y almacenamiento dedicados en su totalidad a Atlas Gym.

⚡ Rendimiento y Cero Demoras

Al no compartir memoria ni procesamiento con otros negocios, la velocidad de consulta de rutinas y cuotas es instantánea tanto en recepción como en los móviles de los alumnos.

🔒 Aislamiento y Privacidad Total

Los datos sensibles de facturación, ingresos de caja y teléfonos de socios están almacenados en una base de datos propia e impenetrable para terceros.

2 Arquitectura Tecnológica Tripartita

Capa 1: Frontend

Next.js 16 + React 19

  • Tailwind CSS v4 & Lucide Icons
  • Portal Administrador y Portal Alumno
  • Tarjetas en cortinas desplegables
  • Auditoría React Doctor 100/100
  • Suite de tests Vitest (28 tests)
Capa 2: Backend

Java con Spring Boot

  • Spring Data JPA (Hibernate)
  • Spring Security con JWT y BCrypt
  • API REST modular y tipada
  • Control de morosidad automático
  • Cron Jobs (@Scheduled) el 1 de cada mes
Capa 3: Datos

MySQL Dedicado

  • Tablas relacionales sólidas
  • Alumnos cargados 1 sola vez
  • Historial de cuotas y entrenamientos
  • Consultas parametrizadas anti-SQLi
  • Backups automáticos programados

3 Cloud Hosting: Operación 24/7/365 Sin Servidor Local

⚠️ Aclaración Operativa Importante: No se requiere tener ninguna computadora encendida en el gimnasio ni en el domicilio de los administradores. Los servidores residen en la nube de Vercel y Railway (con respaldo de Google Cloud y AWS) con generadores eléctricos industriales y conectividad redundante.

Frontend en Vercel (Edge CDN)

Se conecta al repositorio de GitHub. Cada cambio se compila y publica en 1 minuto. Provee certificado SSL automático y distribución global sin costos de mantenimiento.

Backend y BD en Railway / Render

Ejecuta el archivo ejecutable de Spring Boot y el servidor de MySQL en una red privada aislada de ataques externos, con escalabilidad automática.

4 Dominio Institucional y Acceso Móvil

🌐 Dominio Propio Oficial

Se adquiere el dominio atlasgym.com.ar (en NIC.ar) o atlasgym.app. Se configura para que apunte directamente al frontend en Vercel con candado de seguridad HTTPS bancario.

📱 Instalación como PWA (App Móvil)

El alumno accede desde el navegador y con un toque lo instala en la pantalla de inicio de su teléfono. Abre a pantalla completa con el ícono de Atlas Gym sin necesidad de pagar membresías anuales de Google Play ni App Store ($99 USD/año).

Puesta en Marcha en el Gimnasio

Cartel y QR en Recepción

Se coloca un soporte acrílico o banner en el mostrador con el logo de Atlas Gym y un código QR:

app.atlasgym.com.ar

“Escaneá acá para ver tu rutina diaria, anotar tus pesos y consultar tus cuotas”

Elimina por completo el uso de papel impreso y reduce las consultas en recepción.

5 Protocolo de Seguridad y Resguardo de Datos

Área Tecnología / Mecanismo Garantía para Atlas Gym
Tráfico Web HTTPS / TLS v1.3 Comunicaciones 100% cifradas de extremo a extremo. Imposible de espiar en redes WiFi.
Contraseñas BCrypt Password Encoder Las claves nunca se guardan en texto legible. Hashing irreversible con salt dinámico.
Sesiones JWT (JSON Web Tokens) Tokens firmados criptográficamente con expiración y control de revocación.
Control de Acceso RBAC (Roles ADMIN / ALUMNO) Los alumnos solo acceden a sus propios datos; prohibido acceso a caja y balances.
Base de Datos Spring Data JPA / Hibernate Inmunidad total contra inyecciones SQL al utilizar queries parametrizadas.
Copias de Seguridad Daily Automated Snapshots Respaldos diarios automáticos con capacidad de restauración ante cualquier eventualidad.

6 Soporte, Monitoreo y Capacidad de Intervención en Vivo

📊 Logs en Tiempo Real

Desde la consola web de Vercel y Railway se visualizan en vivo los errores, fecha, usuario y línea exacta de código para depuración inmediata.

🔄 Reinicio en 5 Segundos

Si el backend sufriera alguna saturación de hilos o memoria, un botón en el panel de control reinicia el servicio sin afectar los datos guardados.

⏪ Rollback Instantáneo

Si una nueva actualización presentara una falla imprevista, con un solo clic se vuelve en 10 segundos a la versión anterior estable.
